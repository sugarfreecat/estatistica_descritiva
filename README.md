# 📊 Estatística Descritiva e Análise Exploratória de Dados | Descriptive Statistics & Exploratory Data Analysis

<summary>🇧🇷 Português</summary>

## Sobre o projeto

Este repositório reúne estudos práticos de **Estatística Descritiva e Análise Exploratória de Dados (EDA)**, desenvolvidos com Python e bibliotecas voltadas à manipulação, análise e visualização de dados.

O objetivo é compreender conceitos estatísticos fundamentais, explorar diferentes distribuições de dados e interpretar relações entre variáveis por meio de cálculos, gráficos e exercícios práticos.

O material está organizado em notebooks Jupyter, com explicações teóricas, implementações em Python e exemplos contextualizados para facilitar o aprendizado.

## 📚 Conteúdo

<details>
<summary><strong>01. Estatística Descritiva</strong></summary>

Introdução às principais medidas estatísticas utilizadas para descrever e resumir conjuntos de dados.

**Tópicos abordados:**
- Medidas de tendência central: média, mediana e moda.
- Medidas de dispersão: amplitude, variância e desvio padrão.
- Medidas de posição: quartis e percentis.
- Intervalo interquartil (IQR).
- Identificação e interpretação de outliers.
- Histogramas e box plots.

**Aplicação prática:** análise da distribuição das notas finais de uma turma de estudantes.

</details>

<details>
<summary><strong>02. Distribuições de Dados</strong></summary>

Exploração dos diferentes formatos de distribuição e das principais técnicas de visualização de dados.

**Tópicos abordados:**
- Tabelas de frequência.
- Distribuições normal, assimétrica, uniforme e bimodal.
- Assimetria (skewness).
- Histogramas e interpretação de distribuições.
- Gráficos de linhas, barras, colunas e pizza.
- Box plots e diagramas de dispersão.
- Retas de tendência.
- Regra de Tukey para identificação de outliers.

**Aplicação prática:** análise e interpretação de diferentes conjuntos de dados por meio de representações gráficas.

</details>

<details>
<summary><strong>03. Covariância e Correlação</strong></summary>

Estudo das relações entre variáveis numéricas e das medidas utilizadas para identificar sua direção e intensidade.

**Tópicos abordados:**
- Revisão de variância e desvio padrão.
- Cálculo e interpretação da covariância.
- Correlação de Pearson.
- Correlações positivas, negativas e próximas de zero.
- Interpretação de diagramas de dispersão.
- Comparação entre covariância e correlação.
- Influência de outliers na análise de correlação.
- Correlação não implica causalidade.

**Aplicação prática:** investigação da relação entre hábitos dos estudantes, características socioeconômicas e desempenho acadêmico.

</details>

<details>
<summary><strong>04. Revisão de Estatística Descritiva</strong></summary>

Revisão dos principais conceitos estatísticos por meio de exemplos simplificados e exercícios contextualizados.

**Tópicos abordados:**
- Média, mediana e moda.
- Amplitude e desvio padrão.
- Correlação.
- Principais tipos de gráficos e suas aplicações.
- Interpretação de medidas estatísticas.

**Aplicação prática:** miniestudo de caso sobre vendas de uma cafeteria, investigando como valores extremos podem distorcer a média e influenciar decisões de negócio.

</details>

## 🚀 Como executar

Os notebooks foram desenvolvidos para execução em ambientes Jupyter, especialmente Google Colab.

1. Clone este repositório:
   ```bash
   git clone https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git
   ```

2. Acesse o repositório:
   ```bash
   cd SEU-REPOSITORIO
   ```

3. Instale as dependências:
   ```bash
   pip install pandas numpy matplotlib seaborn jupyter
   ```

4. Abra os arquivos `.ipynb` no Jupyter Notebook ou faça upload deles no [Google Colab](https://colab.research.google.com/).

5. Execute as células sequencialmente para acompanhar as explicações, os cálculos e as visualizações.

**Observação:** os notebooks que utilizam a base de dados de estudantes dependem do arquivo `alunos.csv`. Consulte as células de preparação de dados de cada notebook para configurar o caminho e disponibilizar o arquivo corretamente no ambiente de execução.

## About the project

This repository brings together practical studies on **Descriptive Statistics and Exploratory Data Analysis (EDA)**, developed using Python and libraries for data manipulation, analysis, and visualization.

The goal is to understand fundamental statistical concepts, explore different data distributions, and interpret relationships between variables through calculations, visualizations, and practical exercises.

The material is organized into Jupyter Notebooks, combining theoretical explanations, Python implementations, and contextualized examples to support the learning process.

## 📚 Contents

<details>
<summary><strong>01. Descriptive Statistics</strong></summary>

An introduction to the main statistical measures used to describe and summarize datasets.

**Topics covered:**
- Measures of central tendency: mean, median, and mode.
- Measures of dispersion: range, variance, and standard deviation.
- Positional measures: quartiles and percentiles.
- Interquartile range (IQR).
- Outlier detection and interpretation.
- Histograms and box plots.

**Practical application:** analyzing the distribution of students' final grades.

</details>

<details>
<summary><strong>02. Data Distributions</strong></summary>

Exploring different distribution patterns and the main techniques used for data visualization.

**Topics covered:**
- Frequency tables.
- Normal, skewed, uniform, and bimodal distributions.
- Skewness.
- Histograms and distribution interpretation.
- Line, bar, column, and pie charts.
- Box plots and scatter plots.
- Trend lines.
- Tukey's rule for outlier detection.

**Practical application:** analyzing and interpreting different datasets through graphical representations.

</details>

<details>
<summary><strong>03. Covariance and Correlation</strong></summary>

Studying relationships between numerical variables and the statistical measures used to identify their direction and strength.

**Topics covered:**
- Review of variance and standard deviation.
- Covariance calculation and interpretation.
- Pearson correlation.
- Positive, negative, and near-zero correlations.
- Scatter plot interpretation.
- Comparing covariance and correlation.
- The influence of outliers on correlation analysis.
- Correlation does not imply causation.

**Practical application:** investigating relationships between students' habits, socioeconomic characteristics, and academic performance.

</details>

<details>
<summary><strong>04. Descriptive Statistics Review</strong></summary>

Reviewing key statistical concepts through simplified examples and contextualized exercises.

**Topics covered:**
- Mean, median, and mode.
- Range and standard deviation.
- Correlation.
- Common chart types and their applications.
- Statistical measures and interpretation.

**Practical application:** a coffee shop sales case study investigating how extreme values can distort the mean and influence business decisions.

</details>
